## 🔦 What is a Pixel Dungeon Generator

| Term | Explanation |
|---|---|
| WFC | Wave Function Collapse — tiles resolve from constraint sets into a coherent grid |
| Floor Model | A compact neural net that scores a candidate floor plan for "interestingness" before it's accepted |
| Seed | A 64-bit integer; the same seed always produces the same dungeon |
| Room Graph | The abstract node map that connects rooms before they're tiled |
| Encounter Curve | THE pacing schedule — how difficulty ramps across depth levels |
| Prop Pass | The decoration layer that places torches, crates, bones, banners, traps |
| Export Pack | The ZIP bundle a generator run produces (spritesheet + layout + metadata) |

- Generate a full 40-floor dungeon in under 9 seconds on a mid-range GPU.
- Re-roll only the layer you hate — props, spawns, or loot — without losing the layout.
- Feed in a reference image and the model will bias toward that palette and silhouette.
- Export directly into Godot, Unity, or a raw `tilemap.json` you parse yourself.
- Every run ships a deterministic replay file so a bug is reproducible from a seed.

## 🎯 The Problem

- Hand-built roguelike floors take weeks per biome and still feel repetitive after ten runs.
- Cloud generators add latency, accounts, and a subscription just to roll a cave.
- Off-the-shelf WFC demos produce a grid, not a *game* — no pacing, no keys, no bosses.
- Existing tools reject custom palettes, so exported art never matches your project.
- Re-rolling one bad room usually means regenerating the whole dungeon from scratch.
- Seeded reproducibility is either missing or lives behind a server you don't control.

## 🎮 Run the Tool

1. Double-click `.exe`. Windows SmartScreen may warn on first run — click *More info* → *Run anyway*.
2. In the **Generator** panel, enter a 64-bit seed or hit the dice button for a random one.
3. Pick a biome from the dropdown; hybrid biomes appear under the *Blend* tab.
4. Adjust **Encounter Curve**, **Trap Density**, and **Loot Rarity Bias** as needed.
5. Watch the live preview canvas update in real time as you change params.
6. Click **Export** → choose your target engine → save the pack.

For a whole campaign in one shot: switch to the **Batch** tab, set count = 40, paste a seed list, click **Generate All**.

## 📚 Known Issues

| Issue | Fix |
|---|---|
| Preview canvas black on first launch | Update GPU drivers; set *Renderer* to `D3D11` in Settings |
| SmartScreen blocks `.exe` | *More info* → *Run anyway*; add folder to Defender exclusions |
| Export hangs on batch > 200 | Lower batch size or reduce VRAM-heavy biome blends |
| Godot import drops tile variants | Ensure Godot 4.2+ and import with *Use TileSet atlas* |
| Seed shortcode won't resolve | Check the shortcode came from the same major version |
| Lua plugin errors out silently | Run with `--log-level debug` to surface stacktrace |
